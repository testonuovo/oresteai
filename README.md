# 🤖 Oreste AI

Oreste AI è un **assistente vocale italiano online gratis che funziona direttamente nel browser**, senza installazioni e senza app.

## 🚀 Demo Live
👉 https://testonuovo.github.io/oresteai/

---

## 🎯 Descrizione

Oreste AI è un progetto web che permette di controllare il browser tramite la voce e comandi testuali.

È progettato per essere:
- semplice
- gratuito
- accessibile da qualsiasi dispositivo
- completamente eseguito nel browser

---

## 🎤 Funzionalità principali

- 🗣️ Assistente vocale in italiano
- 🌐 Controllo browser con comandi vocali
- 🔎 Ricerca automatica su Google
- 📺 Apertura siti web (YouTube, Instagram, TikTok, ecc.)
- ⬇️ Download intelligente di software
- 🌤️ Meteo in tempo reale
- ⏰ Data e ora dinamiche

---

## 🧠 Tecnologie utilizzate

- HTML5
- CSS3
- JavaScript
- Web Speech API (Speech Recognition)
- Speech Synthesis API
- Open-Meteo API

---

## 💡 Perché è diverso

La maggior parte degli assistenti vocali:
- richiede installazione
- è basata su app o sistemi chiusi
- non funziona nel browser

👉 Oreste AI invece funziona completamente online.
